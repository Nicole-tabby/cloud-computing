# Terraform: Cloudflare R2 Bucket + Public Object Sharing

Creates an R2 bucket, uploads one object into it, and enables public
access so the object can be shared via a single URL.

## Files
| File | Purpose |
|---|---|
| `provider.tf` | Configures the Cloudflare provider (bucket management) and AWS provider pointed at R2's S3-compatible endpoint (object upload) |
| `variables.tf` | All configurable inputs — credentials, student ID, file to upload |
| `main.tf` | The bucket, the object upload, and the public-access toggle |
| `outputs.tf` | Prints the bucket name, object key, and the command to fetch the public URL |
| `.gitignore` | Keeps `.tfvars`, state files, and the `.terraform/` folder out of version control |

## Prerequisites
- Terraform installed (see step-by-step guide)
- A Cloudflare account with an R2 bucket-capable API token
- R2 S3-compatible Access Key ID / Secret Access Key
- `curl` available on PATH (comes with Windows 10+ by default)

## Credentials needed
| Variable | Where to get it |
|---|---|
| `cloudflare_api_token` | Cloudflare dashboard → My Profile → API Tokens → Create Token (needs `Account.Cloudflare R2:Edit` permission) |
| `cloudflare_account_id` | Cloudflare dashboard → right sidebar of any domain, or R2 overview page |
| `r2_access_key_id` / `r2_secret_access_key` | R2 → Manage R2 API Tokens → Create API Token |

Never commit these values. Pass them as environment variables (`TF_VAR_...`)
as shown in the execution steps, not hardcoded in `.tf` files.

## What "public access" means here
Terraform doesn't yet expose R2's public-access toggle as a native
resource argument, so `main.tf` triggers the Cloudflare API directly via
a `local-exec` provisioner during `terraform apply`. This turns on the
bucket's free `pub-xxxxxxxx.r2.dev` subdomain, through which the
uploaded object becomes reachable at:

```
https://pub-xxxxxxxx.r2.dev/<object_key>
```

The exact subdomain is generated by Cloudflare per bucket and isn't
knowable before `apply` runs, so after applying you run one follow-up
`curl` command (shown in the outputs and in the execution guide) to
retrieve it.
